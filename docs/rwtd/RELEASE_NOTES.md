## Qt 3 介面與配色設定

- Global／Web 既有啟動器更新後共用原生 Qt 3 介面，整合 Dashboard、ROI、FARM、解析度對照、輪次統計與配色設定 TASK。
- 新增配色設定頁：選色器、色碼、即時預覽及恢復預設；儲存後同步 Qt 與 Dashboard，重新啟動保留。
- 診斷頁以可讀欄位呈現失敗資訊，包含 OCR 原文、最高信心候選與拒絕原因。

## 模組與 Canvas 管理

- 模組支援重新命名及本機版本回歸；回復舊內容另存為新版本，複製模組從 r1 開始。
- 標頭新增共用垃圾桶，支援模組與 Canvas 的刪除備份、還原及指定備份永久刪除。
- Canvas 新增刪除與資料夾入口；重設視角容納全圖，自動排列按 Chain 分組，單一路徑保持直條。
- 同步十個已確認的模組範本，排除誤刪的迷宮上層刷取。

## 修正

- 實體手機不再沿用 Windows／模擬器擷取設定，避免已選手機卻仍觸發 PC 前景限制。
- 補入上游最大化視窗修正，改善 125% 縮放下畫面與點擊範圍偏移。
- 移除依賴不存在的 BaseTBHTask 的三個舊測試任務。
- 補強數字 OCR 別名與診斷證據。

## 更新方式

本次發布程式碼及依賴更新，沒有重新製作完整安裝包。既有使用者透過啟動器 UPDATE，等待依賴安裝完成後完整重新啟動 OK。
首次安裝仍可使用 v1.0.0 安裝包，再從啟動器更新；舊安裝包沒有改標成新版。

Canvas、模組、配色與 SQLite 的持久資料會保留。本次未發布本機測試 Canvas、草稿或個人備份。
