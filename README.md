# ok-RwtD

Rogue with the Dead 的 OK 執行／更新發佈庫。

此庫包含執行程式、Canvas／模組、辨識模板與已內嵌的 OK 共用套件；完整開發文件與測試另保存在私人開發庫。

- PyAppify 更新來源：`https://github.com/GammaHH/ok-RwtD.git`。
- Global 為原生 Qt 介面，Web 為 Web 介面；初次使用須選擇並連接 Android 裝置，Dashboard 可離線編輯。
- 不含個人 configs、Discord 憑證、歷史日誌、執行環境、資料庫與診斷截圖；本機設定須自行建立。
- `ok`／`pyappify` 已依 OK 工具的發佈方式內嵌，相關第三方授權文字見 `vendor-licenses`。
- main 分支同步執行所需內容；正式版本標籤、安裝包及完整驗證另行處理，不代表已建立或驗收 Release。
